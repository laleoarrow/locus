# Locus / 文迹 0.9.11

修复其他划词弹窗延迟出现、滑入或晚附加 Shadow DOM 时，Locus 工具条先显示再跳位的问题。

- Auto 首次显示前检查位置是否稳定；尺寸和坐标在隐藏状态下完成，显示后仅淡入。
- 清空或替换选区后及时收起旧工具条，避免数字键标注旧内容；工具条按钮和颜色选择器保留正常捕获。
- 滚动和窗口缩放按帧合并定位，窗口改变响应式布局后重新识别浮栏。
- 合并父子节点的重复样式扫描，修复嵌套 Shadow DOM 样式更新后漏识别浮栏。

Auto 静态场景的设计等待由约 300 ms 改为约 400 ms；移动中的浮栏延长等待，上限 700 ms。数字选色和明确指定上/下方仍即时处理。任意更晚出现或持续变化的弹窗仍需后续动态避让。

全部验证使用独立无头浏览器和临时配置；用户正在使用的 Edge、笔记、设置与安装目录未操作。详见 [独立审查与验证](rival-audit-0.9.11/REPORT.md)。

类型检查、497 项单元测试和完整 106 项浏览器回归通过。最终 ZIP 在真实必应搜索气泡、7 类模拟浮栏和快速重选滚动场景复测通过。
