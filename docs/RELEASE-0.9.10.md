# Locus / 文迹 0.9.10

工具条首次显示时直接出现在已计算好的位置，减少“先出现、再跳开”的过程。

- Auto 首次显示前隐藏等待约 300 ms，让常见的网页搜索或翻译浮栏先出现，再测量当前选区和障碍。
- 在不可见状态下测量工具条并设置位置，入场只淡入，不再位移或缩放。
- 等待期间仍可直接按数字选色；取消、重选、保存和禁用不会留下过时的显示任务。
- 手动指定 Above / Below 保持即时显示。显示后继续处理后出现或移动的浮栏，以及页面滚动和重排。

任意更晚出现的浮栏无法提前预测；本次改动解决首次显示时的常见竞争，保留必要的后续避让。验证方法见 [首次显示记录](TOOLBAR-0.9.10.md)。

类型检查、481 项单元测试和完整 101 项浏览器回归通过。

全部测试使用隔离无头浏览器、本地页面及模拟服务，没有操作用户工作窗口、真实网盘或正在使用的扩展安装目录。
