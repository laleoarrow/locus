# Locus / 文迹 0.9.9

修正两种会把工具条推远的定位错误：

- 页面根元素平移或缩放时，按实际视口坐标定位和避让，避免重复换算坐标。
- 选中高容器里的短文字或单个标点时，按实际文字范围定位；保留完整原始选区用于保存标注。
- 滚动、窗口调整和页面重排后持续跟随；不改变 Auto 检查频率，静止位置继续跳过重复写入。

隔离浏览器中，缩放场景的距离由约 405 px 降至 10 px，高内联容器场景由 226 px 降至 10 px。完整场景、测量方法及边界见 [定位验证记录](TOOLBAR-0.9.9.md)。这些结果来自复现页面，不代表已确认用户的必应页面采用同样的布局方式。

类型检查、469 项单元测试和完整 96 项浏览器回归通过。

测试只使用无界面的临时浏览器、本地页面及模拟服务；未替换正在使用的扩展目录，也未操作用户窗口或真实网盘。
