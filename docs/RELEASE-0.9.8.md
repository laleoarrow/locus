# Locus / 文迹 0.9.8

## 保留原有能力，减少运行开销

- 无标注或只有图片标注的页面不再构建全文索引。保存文字笔记、调整偏好和改色不再无谓重建整页标注。
- 图片批次共用查询及祖先测量，先测量再更新边框；静止边框跳过重复样式赋值。
- 编辑一条 Library 笔记只更新该条目，保留跨视图草稿、失败重试和冲突保护。
- Library 只读取已标注页面的相关元数据，避免无关浏览记录触发重读；分组和静态 Markdown 按实际变化更新。
- 工具条跳过不变的 DOM 更新，保留全部 Auto 测量和避让检查。

实测工作量：200 条笔记中输入 20 次，其他行渲染从 3980 次降至 0；100 张图片中的 30 个锚点，整页图片查询从 30 次降至 1。完整场景、指标定义和边界见 [性能记录](PERFORMANCE-0.9.8.md)。这些计数不是整机提速或耗电下降百分比。

类型检查、458 项单元测试和完整 93 项浏览器回归全部通过。测试仅使用无头临时浏览器、本地数据与模拟服务；没有访问真实笔记/网盘，也没有替换用户正在使用的扩展目录。
