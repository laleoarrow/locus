# 独立划词浮栏审查与性能验证 · 0.9.11

## 范围与隔离

针对 0.9.10 工具条首次闪跳、距离、选区失效和页面几何开销做独立审查。浏览器为临时配置的无头 Chromium；基线直接解压未修改的 0.9.10 Edge ZIP，修复后同样加载最终 0.9.11 Edge ZIP。用户工作 Edge、安装目录、真实笔记、设置及网盘/LLM 账户均未操作。所有模拟 API/WebDAV 只使用本机测试服务。

真实必应使用公开搜索 `https://cn.bing.com/search?q=hi`、`zh-CN` 环境和真实鼠标拖选。最终测试实际显示了必应自带搜索气泡；另加入明确标记的测试浮栏，验证气泡与受控第三方式浮栏的组合。未安装豆包等第三方扩展，因此不能声称已验证它们所有版本。基线阶段只测量零尺寸 Quick Search 容器，漏计了可见子节点；最终记录已修正为可见子节点实际矩形，并在原生拖选前等待必应结果重排稳定。

## 已复现并修复的问题

| 问题 | 复现及影响 | 修复 |
| --- | --- | --- |
| 首次显示早于晚到浮栏 | 350 ms 出现的浮栏导致 83 px 跳动、18 个重叠帧 | 首次测量仍隐藏，等待几何连续稳定再显示 |
| 首次显示早于入场动画结束 | 250 ms 出现、继续滑入 240 ms：83 px 跳动、13 个重叠帧 | 对选区与障碍矩形采样，稳定窗口覆盖入场动画 |
| 既有宿主晚附加 Shadow Root | 开放/关闭根 350 ms 附加；基线 1.1 s 采样中分别 90/91 个重叠帧 | 最早显示前额外探测一次缓存宿主，再参与稳定检查 |
| 可见工具条保留过期选区 | 页面清空或更换 Selection 后旧 Range 仍连接，数字键可能标注旧内容 | 选区变化和快捷键检查当前目标，保留工具条/原生颜色选择器的正常捕获 |
| 缩放漏识别响应式浮栏 | 普通元素通过媒体查询变为 fixed 后不在缓存中；同步刷新还早于失效标记 | resize 使分类失效；缩放/滚动共用下一帧刷新 |
| 同批父子变更重复扫描 | 父节点和 250 个子节点同时改变时重复遍历 | 被脏祖先覆盖的子树只遍历一次 |
| 嵌套 Shadow DOM 重分类丢失上下文 | 内部样式表更新后绝对定位宿主被按外层普通元素判断 | 使用宿主实际 Shadow DOM 上下文重新分类 |

## 响应时间与工作量

Auto 首次在 300 ms 时隐藏测量，之后每 50 ms 采样；最早 400 ms 显示，几何需稳定 100 ms，等待上限 700 ms。静态场景设计等待由约 300 ms 增至约 400 ms，这是避免竞争闪跳的延迟取舍，不能描述为首次显示更快。数字选色、显式 Above/Below 仍立即处理；显示后的 200 ms 动态避让保留。

| 测量 | 基线 | 修复后 | 含义 |
| --- | ---: | ---: | --- |
| 20 次同帧滚动定位 | 20 次刷新 | 1 次刷新 | 减少重复布局工作，缩放与嵌套滚动也合并 |
| 同批父子变更的子树样式读取 | 751 | 251 | 减少 66.6%，不降低后续检测频率 |
| 5000 宿主额外 Shadow Root 探测 | 初始扫描 5002 次样式读取 | 强制探测仅 8 次样式读取 | 5004 次宿主查询，只在初显前额外执行一次；随后 10 次检测为 0 次宿主查询 |

缩放期间图片环由原来的 150 ms 防抖改为逐帧跟随，以改善响应；这部分未测得 CPU 降幅。上述计数来自专项回归；不等于整体 CPU、内存或浏览器耗时降幅。Node/jsdom 中强制宿主探测约 2.15 ms 仅作诊断，不代表真实网页延迟。

## 验证

类型检查、497 项单元测试与完整 106 项浏览器测试通过。E107 覆盖 350 ms 浮栏、滑入浮栏及开放/关闭晚附加 Shadow Root；E108 覆盖高字典卡片内单个标点。逐帧检查可见位置、与选区距离、遮挡和入场变换。另检查取消、键盘重选、图片与文字快捷键、颜色选择器、滚动/缩放、批量编辑、草稿、同步及导入导出。

发行包 CRC、0.9.11 版本和固定 key 检查通过。Chrome/Edge 包解压内容一致，商店包仅移除 manifest key，生产校验器通过。散列见 [packages.json](packages.json)。

## 边界

有限的初显等待无法预测任意未来弹窗。700 ms 后才出现、持续变化或稍后新附加的 Shadow Root，仍可能触发必要的后续避让；浏览器原生菜单和桌面浮层不在网页 DOM 中，无法测量。本次零闪跳结论限于记录的测试场景，未宣称所有网站或其他扩展版本永远零位移。
